# 清明上河图 · 三维场景扩充（对外快照）

**仓库地址：https://github.com/derekwalldevin-wen/qingming-scene-expansion**

这是「清明上河图建筑扩充与整体场景」项目的**发布用快照**：只含文档、截图、报表与可追溯元数据。
**不含** GLB 模型、资产 zip、离线预览大 HTML（那些体积过大，见 `docs/进度与交接.md` 的说明）。

## 内容

| 目录 | 内容 |

| `docs/` | 作品说明、进度与交接、对照原图审计、建筑重试记录、Blender 管线说明、已知问题 |

## 一句话说明

在《清明上河图》原画卷基础上做的三维场景扩充实验：13 处锚点建筑替换（其中 8 个锚点已升级到 v2/v3）、
石板街 + 宋式木栏 + 石砌驳岸 + 围合城墙、12 组摊位/20 只灯笼、9 个绑骨职业人物（2 人沿街行走）、
4 簇生活场景（3 个克隆人物）、6 站导览条；全部**未并入冻结版本、未改 dist、未对外发布**。

## 重要边界

- 这是**AI 候选 + 人工比对**的实验成果，不是整卷精确复原；背面、进深、柱跨多为推定。
- 视觉、交互与兼容性由人验收；文本只写"据画面可见"的内容。
- 付费生成有过失败与过期记录，全部在 `meta/paid-task-ledger.json` 与 `docs/建筑重试记录.md` 中如实登记。
