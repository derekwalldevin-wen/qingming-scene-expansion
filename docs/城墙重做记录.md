# 城墙重做记录（2026-11-11）

用户反馈"城墙太丑"，要求参考北宋资料。查证要点：

- 北宋东京（汴京）外城是**夯土版筑**，不是灰砖包砌；砖包城墙主要见于明清；
- **城门墩台用砖**，门道为排叉柱（梯形木构）承托过梁；
- 城墙上有**女墙与垛口**，城外每隔一段有**马面（敌台）**凸出。

参考：[开封北宋城门遗址考古报道](http://news.youth.cn/hotnews_41880/202407/t20240712_15376521.htm)、[北宋东京城形制与规模](https://osgeo.cn/post/adc62/)、[开封城墙沿革](http://mp.weixin.qq.com/s?__biz=MzA5MjA0ODE0MQ==&mid=2650912338&idx=7&sn=1e835bd20d4432c59f6c0a02621ee1bb)（访问受限，仅作方向参考）。

## 改动（三轮，全部程序化，0 积分）

| 项 | 之前 | 现在 |
|---|---|---|
| 材质 | 灰砖贴图 + 竖直薄墙 | **自建夯土贴图**（512²，底色 `#b9a488`，每 24px 一道横向夯层线，稀疏石粒 + 淡冲刷痕，avgL≈0.42，配 normal/roughness） |
| 墙体剖面 | 约 1 m 厚竖直墙 | **收分墙体**：底宽 6.4 m、顶宽 4.6 m、高 9.2 m（坡度≈1:10.2） |
| 墙顶 | 平顶 | 外侧女墙 1.15 m + **138 个连续垛口**；内侧宇墙 0.75 m；0.8 m 马道 + 压顶石带 + 挡脚土坎 |
| 马面 | 无 | **5 处**（每 70 m，凸出 3.2 m、宽 6 m、顶加女墙） |
| 立面 | 大面积平板 | 每 7.2 m 一道竖向收分棱（63 道）、板段亮度 0.96–1.04、底部渐变 ×0.82、整体压暗 ×0.92、偏暖 ×(1.03,0.99,0.94) |
| 墙脚 | 无 | 0.5 m 石砌基座 + **18 个排水石嘴**（凸出 0.35 m） |
| 城门 | 与墙同材质 | 两侧**砖砌墩台**（`#8a8076`、8×6×9.6 m、3 道砖腰线）+ 两侧各 5 根排叉柱 + 阑额 |
| 转角 | 大平面硬接 | 4 处角墩（miter） |
| draw call | 旧墙 3 | **5**（stone/body/cap/brick/wood），净增 2 |

运行时实测：`street.wall.material='rammed-earth'`、`merlons=138`、`bastions=5`、`cornerPiers=4`、`verticalRibs.count=63`、`scuppers.count=18`、`drawCalls=5`、`errors=[]`。

## 仍不够好的地方（如实）

1. 从城内看，部分角度仍是**大块浅土色平面**（尤其转角墩与背街长段），竖向棱的 5% 明暗差在远距离读不出来；
2. 马面与角墩是简化方盒，缺少北宋城墙常见的**木构战棚/敌楼**；
3. 垛口是"顶部齿状块"，不是把女墙真正切出垛口；
4. 墙面没有箭孔/瞭望孔等细部；
5. 夯土表面是程序化贴图，近看仍偏"均匀色块"。
