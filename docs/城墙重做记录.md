# 城墙重做记录（2026-11-11）

用户反馈"城墙太丑"，要求参考北宋资料；随后追加：**加木构战棚与敌楼、垛口做真、加箭孔、城墙要有厚度**；再追加：**收分更墩实、战棚敌楼加碰撞、登城台阶与马道可通行、垛口端部收头**。

## 查证要点

- 北宋东京（汴京）外城是**夯土版筑**，不是灰砖包砌；砖包城墙主要见于明清；
- **城门墩台用砖**，门道为排叉柱（梯形木构）承托过梁；
- 城墙上有**女墙与垛口**，城外每隔一段有**马面（敌台）**；城墙上设**战棚、敌楼（团楼）** 等木构设施。

参考：[开封北宋城门遗址考古报道](http://news.youth.cn/hotnews_41880/202407/t20240712_15376521.htm)、[北宋东京城形制与规模](https://osgeo.cn/post/adc62/)、[开封城墙沿革](http://mp.weixin.qq.com/s?__biz=MzA5MjA0ODE0MQ==&mid=2650912338&idx=7&sn=1e835bd20d4432c59f6c0a02621ee1bb)（访问受限，仅作方向参考）。

## 最终做法（五轮，全部程序化，0 积分）

| 项 | 最终值 |
|---|---|
| 夯土材质 | 自建 512² 贴图（底色 `#b9a488`、每 24px 横向夯层线、稀疏石粒、淡冲刷痕、avgL≈0.42），配 normal/roughness，UV 1.6 m×1.2 m |
| 墙体剖面 | **底宽 8.2 m / 顶宽 6.0 m / 高 9.2 m**，batter **0.1196（≈1:8.36）**；马道净宽 5.0 m；矮墙段 7.0/5.0、高 8.2 m |
| 墙脚/墙顶 | 石基高 0.65 m、外扩 0.3 m；18 个排水石嘴；压顶石带 0.35 m；马道挡脚土坎 |
| 垛口 | 下部实心墙 0.45 m + 上部垛墙段（1.5×0.7×0.55，每 2.6 m），缺口 1.1×0.7 m **真空出来**；**垛口 124 个**；段端 0.55 m 半垛收头（**endCaps 120**）；东墙相位错开 1.3 m |
| 箭孔 | 垛墙每段 1 个（0.10×0.45）+ 墙身上部每 5 m 1 个（0.12×0.5），内壁顶点色 ×0.55 |
| 马面 | 5 处，宽 6.4 m、凸出 3.2 m、顶加 0.6 m 女墙 |
| 战棚 | **5 座**（4.2×2.6 m、四柱、单坡瓦顶、栏杆），每座 2.4 m 深 collider，留 ≥3.6 m 通道 |
| 敌楼 | **3 座**（2 处马面顶 + 1 处转角，两层、相对墙顶高 5.4 m），同样加 collider |
| 城门 | 砖砌墩台（`#8a8076`、8×6×9.6 m、3 道砖腰线）+ 两侧各 5 根排叉柱 + 阑额 |
| 登城台阶 | x≈208.5、z 30–52，宽 2.4 m、每级 0.18 m、**55 级**、两侧扶墙 collider + 顶部观景平台（4×3 m） |
| draw call | 墙相关 **5**（stone/body/cap/brick/wood） |

运行时实测：`batter=0.1196`、`merlons=124`、`endCaps=120`、`defenseColliders=8`、`stairs.steps=55`、`walkable.supported=false`、`drawCalls=5`、`errors=[]`。

## 马道可通行：**本轮未做到（如实）**

- 判定结论：`walkable={supported:false, mode:'platform-only'}`。
- 原因：玩家 Y 由 dist 的 `world.floor(x,z)` 决定；要在 overlay 里"走上墙顶"必须包裹该函数（墙顶矩形返 9.2 m、台阶做线性坡道），可能影响寻路、相机与其它系统，且无法在无浏览器条件下充分验证。
- 现状：登城台阶做到墙顶，顶端有一个 4×3 m 观景平台 collider，但**马道本身不可行走**；真正可走需要修改 dist 的地面高度逻辑，超出"不改 dist"的约束。

## 仍不够好的地方

1. 战棚/敌楼 collider 只有 2.4 m 深（小于建筑 4.2/4.6 m），玩家可从后半部穿过；
2. 台阶 22 m 内升 9.85 m（均坡约 24°），最后一级与墙顶可能不完全齐平；
3. 半垛收头可能与首末完整垛墙轻微重叠，近看可能出现双块；
4. 箭孔是内凹深色几何而非布尔切洞；
5. 敌楼是简化两层木构，缺栏杆细部。
