# 三分钟导读（给评委/观众）

## 一分钟：这是什么

以《清明上河图》原画卷为依据，做了一次**三维场景扩充实验**：把画里可以核实位置的建筑，做成能走进去的三维场景，并把街面、河岸、城墙这些"整卷骨架"补齐。全部成果放在独立目录，**没有并入正式版、没有修改发布包**。

## 一分钟：能看什么

| 看什么 | 打开方式 |
|---|---|
| 原画对照 | `report/gallery-guide.html`（六站：郊野 / 汴河码头 / 虹桥 / 城门 / 城内街市 / 城墙，左原画、右实拍） |
| 改了什么 | `report/compare-report.html`（6 组"原画 → 修改前 → 修改后"） |
| 三十件候选 | `offline-preview/buildings-selected.html`（可旋转、可导出原始 GLB） |
| **进场景走** | `integration-preview/Play-Windows.bat`（等"画卷已备"→ 步入汴京；按 `[` `]` 切换六站导览） |

值得停下来看的三处：
1. **城门**——单檐三开间门屋，中间可穿行，门洞 26 m 保持通行；
2. **河岸**——石砌驳岸 + 宋式深色木栏杆（立柱、望柱、石础），不是现代金属栏杆；
3. **街市**——12 组摊位、檐口灯笼、12 个不同职业的绑骨人物，其中货郎与差役沿街行走。

## 一分钟：边界在哪

- 这是**AI 候选 + 人工比对**，不是整卷精确复原：背面、进深、柱跨多为推定；城墙是程序化补全，导览里明确标注"非逐段考证"。
- 屋顶已统一为自建深灰瓦材质，但瓦纹与坡度对齐仍不完美，近看像"贴图瓦"。
- 有过失败：4 次产物因 2 小时链接过期未取到（79 积分）；C05 有一次服务商终态失败；C08/B09-06 各有候选生成但不合格而未采用——全部记在 `provider/ledger.json` 与 `guided-retry-20261110/README.md`。
- 冻结版 r1（849 MB，SHA-256 `B88E652A…`）与 `dist/` 三文件 SHA 均未变，核对结果见 `DELIVERY-CHECKLIST.md`。
